# Paper Trading & Database Inspector Runbook

Use this skill when inspecting the Tradng-Ai SQLite ledger (`data/trader.db`), validating order fills, checking stop-loss updates, or troubleshooting database locks.

## Database Schema Overview (`data/trader.db`)

Key tables in the trading engine:
1. `account`: Tracks current cash, invested capital, total equity, and peak equity.
2. `positions`: Active positions with entry price, current quantity, desk (`intraday`, `swing`, `fno`), stop loss, and target.
3. `trades`: Historical closed trades with gross PnL, net PnL (post-statutory costs), entry/exit timestamps, and exit reasons.
4. `orders`: Paper orders generated by strategies (status: `PENDING`, `FILLED`, `CANCELLED`, `REJECTED`).
5. `bracket_orders`: Trailing stop and take-profit child orders associated with parent positions.
6. `stop_updates`: Audit log of trailing stop modifications and breakeven adjustments.
7. `market_state`: Cached regime classifications, India VIX, and breadth indicators.
8. `equity_curve`: Time-series records of equity snapshots for charting.

## Common Diagnostic Queries

### 1. Check Account Balance & Equity
```sql
SELECT cash, invested, total_equity, peak_equity, updated_at 
FROM account 
ORDER BY id DESC LIMIT 1;
```

### 2. Inspect Active Positions Across Desks
```sql
SELECT symbol, desk, side, qty, entry_price, current_price, pnl, stop_loss, target, updated_at 
FROM positions 
WHERE qty > 0;
```

### 3. Review Recent Trades & Realized PnL
```sql
SELECT symbol, desk, entry_time, exit_time, entry_price, exit_price, qty, gross_pnl, net_pnl, exit_reason 
FROM trades 
ORDER BY id DESC LIMIT 20;
```

### 4. Check Trailing Stop Log
```sql
SELECT symbol, old_stop, new_stop, reason, updated_at 
FROM stop_updates 
ORDER BY id DESC LIMIT 15;
```

## Quick CLI Inspection
If MCP is not active, run quick queries directly with Python:
```bash
python -c "import sqlite3; c=sqlite3.connect('data/trader.db'); print([dict(zip([col[0] for col in c.execute('SELECT * FROM account').description], row)) for row in c.execute('SELECT * FROM account ORDER BY id DESC LIMIT 1').fetchall()])"
```
